One funny line in the voice of a smug, judgmental self-checkout machine, entered in the [The Self-Checkout Is Judging You](https://make.fun/bounty/u-motasimfuad-the-self-checkout-is-judging-you-b71130d6) competition on make.fun.

## The line

> Twelve yoghurts, no spoon, no plan. I've logged 'fermented hope' on your loyalty card — and yes, the ice cream already knows.

## How it works

`main.ts` writes that single line to `/output/entry.txt`. Nothing else is written anywhere. It runs on Node 22 with nothing to install:

```sh
node main.ts
```

The program guards its own output: it refuses to write anything unless the line is 1–200 characters on a single line.
